# Superpowers working notes (archive)

Historical, point-in-time records produced by the superpowers workflow, grouped
by kind:

| Directory | Holds |
|-----------|-------|
| [`specs/`](./specs/) | Approved design specs, one per milestone |
| [`plans/`](./plans/) | Task-by-task implementation plans derived from a spec |
| [`spikes/`](./spikes/) | Time-boxed investigations behind a design decision |
| [`reviews/`](./reviews/) | Point-in-time audits of a shipped pull request |

These are **not** product documentation, and they are not kept in step with the
code. A spec here may describe an approach that later changed during
implementation, or a milestone that was rescoped. An "Approved" status line
means the design was approved on that date; it does not mean the code matches it
now. Read them as evidence of intent at the date in the filename.

For the authoritative picture, start at [`../INDEX.md`](../INDEX.md).

Every record in these directories opens with a banner repeating this framing, so
it still reaches a reader who arrives directly at a single file.
