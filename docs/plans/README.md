# Design plans (archive)

Historical, point-in-time working documents. Each file is named
`<date>-<slug>.md` and records the design or implementation plan as it stood on
that date.

These are **not** product documentation, and they are not kept in step with the
code. A plan here may describe work that later shipped differently, shipped much
later, or was abandoned. Read them as evidence of what was intended on the date
in the filename, never as a description of how Vision Studio behaves today.

For the authoritative picture, start at [`../INDEX.md`](../INDEX.md).

Every record in this directory opens with a banner repeating this framing, so it
still reaches a reader who arrives directly at a single file.
