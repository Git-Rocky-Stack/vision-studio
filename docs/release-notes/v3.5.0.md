The first code-signed Windows release, and the largest update since 3.0. It includes the full design and engineering audit planned for 3.4.2 (that version was never published and became 3.5.0) and a second audit's security and reliability fixes. The Canvas also gains retouching and vector tools.

## Before you upgrade

3.5.0 raises the hardware and OS floor. Check these before installing:

- **NVIDIA GPUs: Turing (RTX 20 / GTX 16) or newer, RTX 50-series included, on driver 580 or newer.** The bundled PyTorch is now 2.14.1 on CUDA 13.2, which has no kernels for older cards. A GTX 10-series or older card still works, but generation runs on the CPU, and the Foundry hardware panel and first-run setup say why.
- **macOS 14 (Sonoma) or newer on Apple Silicon.** The bundled PyTorch arm64 build requires it, and the installer refuses older systems.
- **Windows 3.4.x installs need one manual download.** 3.4.x builds were unsigned, and their updater expects a publisher name that no signed build carries. Install 3.5.0 from the download page. From 3.5.0 on, in-app updates verify the new signature and install normally.
- **Disk:** the Windows backend is about 2.4 GB larger, because Torch-TensorRT is now bundled. TensorRT stays off until a model family passes the verification sweep, and Settings says so.

## Highlights

**Canvas retouching and vector tools.** Clone Stamp (S) has aligned sampling. Heal (J) uses Poisson blending, so patches have no seam, and with no source set it spot-heals. Shape (U) draws rectangles, ellipses, lines and arrows; Pen (P) draws open or closed paths. Retouching is non-destructive: every stroke is a single undo step, Before/After shows the original, and exports include it. A new Tool options panel carries brush size, hardness, opacity and colour, and [ and ] change the brush size.

**Generation you can trust.** FLUX, FLUX Fill and SD 3.5 render correctly on the local GPU (a scheduler swap had broken their flow-matching scheduler). Generation jobs survive a backend restart, and a crashed backend restarts itself. Billed OpenRouter and Hugging Face generations are sent once, never retried on a timeout. Cancelled jobs stay cancelled, and only one model is held in VRAM at a time.

**Nothing to install but the app.** The AI backend ships as a hash-locked bundle inside every installer and checks itself at startup. Python is not needed.

**Faster.** The startup bundle is 782 kB -> 442 kB (gzip 205 -> 120 kB). App state is saved at most once every 400 ms instead of on every change, and saved state now lives in IndexedDB.

## Security

- **The UI can only reach the app's own folders.** Every file-system call resolves real paths and rejects path traversal and symlink escapes. The backend serves media only from the same allow-list.
- **Every IPC channel is typed and validated** against one shared contract, and only the app's own window can call it.
- **The local backend is authenticated.** An HMAC handshake at launch, plus a session header on every HTTP and WebSocket call, stops other local processes from driving the GPU or reading outputs.
- **A strict Content Security Policy** (no `unsafe-inline`), and permission requests are denied unless allowed.
- **API keys are encrypted** with the OS keychain and never appear in logs or error output.
- **Supply chain:** every GitHub Action is pinned to a commit SHA, the backend installs with `--require-hashes`, `pip-audit` runs on every pull request, and Dependabot watches npm and Actions. `npm audit` reports zero vulnerabilities, for both the shipped and the full dependency tree.
- **Runtime:** Electron 45.3.1.

## Also changed

- Updates download only when you ask: **Settings > About > Download update**.
- Ctrl+W no longer closes the window. Closing while work is running asks first, and launching a second copy focuses the one already open.
- Removed the video End Frame control: no backend path ever used it.
- Dozens of wiring fixes: pipelines, collections, Region Lock, Canvas undo and redo, the adjustment sliders and filters, Quick Generate on the Hugging Face route, and errors that used to fail silently. The full list is in the [changelog](https://github.com/Git-Rocky-Stack/vision-studio/blob/main/CHANGELOG.md).

## Install

Download for your platform from **[vision-studio-x.com/download](https://vision-studio-x.com/download)**: Windows x64, macOS on Apple Silicon, or Linux x64. The AI backend is bundled. Model weights download later, with your consent, through the in-app Foundry.

**Windows builds are code-signed** through Azure Artifact Signing, with publisher **Sharif Elsalaymeh**. While the new signing identity builds reputation, SmartScreen may still show "Windows protected your PC" with that publisher name. Click **More info -> Run anyway**. "Unknown publisher" would mean the signature is not valid, so do not run that file. Report it instead.

**macOS builds are not yet notarized.** On macOS 15 or later, try to open the app once, then click **Open Anyway** under **System Settings -> Privacy & Security**; on macOS 14, **right-click -> Open**. On Linux, `chmod +x` the AppImage.

See [SECURITY.md](https://github.com/Git-Rocky-Stack/vision-studio/blob/main/SECURITY.md) for the supported versions and how to report a vulnerability.
